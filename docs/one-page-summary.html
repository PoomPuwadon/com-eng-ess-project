What it does

A multiplayer 3D web world: an absurdly luxurious, satirical financial firm in two towers that you can walk through in the browser. It runs 24/7 on a server simulation where AI employees trade, research and bet using real-world free data with fake money only. Players sign up as visitors, explore the lobby, trading floor, leisure suites and arenas, chat, and play. Staff roles (CEO / admins) control budgets, balances and clearances.

Features built

  • Accounts: sign-up, log-in, log-out; scrypt-hashed passwords; roles (Visitor, CEO, Staff admin).
  • 3D building: lobby, Office Tower, Visitors' Tower, glass bridge, vault, working elevators, minimap.
  • Multiplayer: WebSocket presence, text chat, per-visitor clearances.
  • Fake-money ledger: append-only double-entry SQLite ledger; vault, budgets, cash-robot trips, audit log.
  • Trading floor: real delayed US stock data, rival AI desks, risk officer veto, live P&L screens.
  • Leisure suite & arenas: roulette and table games, football arena (real fixtures, odds, crests), Muay Thai ring, horse racing, Thai lottery room.
  • AI agents: Claude and Gemini side by side; agents propose, server code validates every money action.
  • Model League: dashboard ranking Claude vs Gemini vs rule book by P&L, calls and cost.
  • Chart Desk (Computer Vision): upload a chart image, the AI returns an UP/DOWN verdict with reasoning.
  • Cost control: monthly LLM cap with circuit breaker; rule-book fallback with no API key.

External APIs and how they are used

Yahoo Finance / Finnhub (stock quotes and charts) · football-data.org (fixtures, results, crests) · Thai Government Lottery Office API (official draw results) · Anthropic Claude API and Google Gemini API (agent decisions, research notes, chart reading). All free tiers; keys stay on the server in .env.local, never in client code.

Tech stack

Three.js + Vite (client, instanced low-poly rendering) · Node.js server with WebSockets (ws) · SQLite (node:sqlite, WAL) · Claude SDK + Gemini REST · ~24,000 lines of JavaScript, 45+ commits, server tests via node --test.

Mock data only: all money is fake, all visitors and staff are invented. Fiction note: the firm's "wellness" tower and its euphemistic copy are satire.
